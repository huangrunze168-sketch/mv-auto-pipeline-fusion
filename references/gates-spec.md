# 八道关规格 · 逐项机检

> 双关制：机器自审（`scripts/gate_checks.py`）+ HTML 页面人审。硬门禁（关 5/6）退出码非 0 一律阻断，无豁免通道。每关跑完用 `assets/gate_page_template.html` 出页面到 `gates/`。

| 关 | 步 | 档位 | 输入 | 机器检查 | 通过判据 |
|---|---|---|---|---|---|
| 1 | 1 | 结构 | 原曲 + 官方歌词 + ASR 结果 | ① 行数与官方歌词一致（一行不能少）② 时间单调递增无重叠 ③ 全曲时长与音频实测差 <0.1s ④ 间奏显式标注 ⑤ confidence<0.85 的行进入待核清单 | ①②③④ 全过；待核行需用户点头后清除 |
| 2 | 2 | 结构 | 用户风格诉求 | ① 风格五要素齐（视觉关键词/色板/服装/比例/分辨率）② fingerprint 已生成 ③ locked=true | 全过，且**必须先于关 3**（顺序机检：关 3 读取时校验 style.locked） |
| 3 | 3 | 结构 | 主人公图 / 资产 | ① 图指纹化（sha256）② 上传记录唯一（同指纹不重复上传）③ 无主角模式时本关标记 skipped | 全过或 skipped |
| 4 | 4 | 结构 | timeline.json | ① 每个 window 的切点落在歌词行尾或间奏边界（容差 0.2s）② 一句歌词未被切成两半 ③ 每段已定 shot_type 与 lip_sync ④ 覆盖全部歌词行 | 全过 |
| **5** | 5 | ⛔硬 | prompts/*.json + timeline + style | **14 项机检**（11 基础 + 3 扩展项：具体瞬间 / 场景母版一致 / 参考职责），清单见 `prompt-framework.md` | 14/14 全绿才放行，通过后写 prompt_fingerprint |
| **6** | 6 | ⛔硬 | storyboard.json + timeline | ① 窗口首尾相接（相邻 start=prev end，容差 0.001）② 合计=全曲长（容差 0.05s）③ 口型镜头景别 ∈ 白名单四类 ④ 口型占比 ∈ [0.35, 0.55] ⑤ 连续口型 ≤3 ⑥ 无手写秒数 ⑦ 全曲无空洞无重叠 | 全过 |
| 7 | 7 | 试产 | 真实节点表 | ⓪ 后端门限：视频生成后端由用户提供（名称/凭证/并发/真钱封顶），skill 只提问不内置；未提供则不进入本关 ① 已拉取生成平台真实节点/字段表（不许按猜的提交）② 首镜跑通：契约、分辨率、音频策略全实测 ③ 契约不符=拒绝提交 | 首镜产物可下载且时长≈窗口长 |
| 8 | 8 | 生成 | clips/ | ① 每段经 duration_fit.py 贴合（实测=窗口长）② 断点续跑状态一致 ③ 在途任务有 salvage 记录 ④ 每 10–15 分钟汇报一次 | 全段 status=fitted |
| 8.5 | 9 | 生成 | 重抽请求 | ① 先走局部修复判定：主导问题 ≤3 且独立 → repair 路径（局部修），否则整段重抽 ② 各段零依赖确认 ③ prompt 指纹比对：改过 → 自动退回关 5（修复不豁免） | 抽卡前后指纹账目一致 |
| **7/8 验** | 10 | 验收 | 成片 ×2 | **对齐三验**（align_verify.py）：① 各段时长合计=原曲长 ② 逐段波形最优滞后 ≈0 且相关度达标 ③ 口型段人声能量非空 | 三验全过才可说「做完了」 |

## 重抽卡指纹规则（关 5 ↔ 步 9 闭环）

```
重抽请求 → 比对 prompts/SHxxx.json 当前指纹 vs storyboard.prompt_fingerprint
  ├─ 一致 → 直接重抽（同批文）
  └─ 不一致 → 提示词被改过 → storyboard.prompt_fingerprint 置 null
              → 该段退回关 5 重审 → 全绿后重新签指纹 → 才可提交
```

## HTML 关页约定

- 文件名：`gates/gate1.html` … `gates/gate8.html`（重审覆盖写，保留 `_prev` 备份一份）
- 页头三件套：关卡号 + 通过/未通过徽章 + 机检计数（如 `11/11`）
- 逐段表格列出：shot_id / 检查项 / 结果 / 证据值；失败项红标并给出修复建议
- 页面零外部依赖（内联样式），与 `assets/gate_page_template.html` 同源
